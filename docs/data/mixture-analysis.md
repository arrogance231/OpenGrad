# Mixture analysis

Mixtures are compared by measured sample count, token count, source provenance, decision class, capability, trajectory structure, catalogue conditions, retention share, and counterfactual coverage. The historical 35/15/15/15/10/10 source proportions remain M0 hypotheses only; sample percentages must not be confused with token percentages or behavioral coverage.

Use `uv run opengrad-data-audit --records <canonical.jsonl> --json` to emit machine-readable and human-readable coverage. The audit measures materialized records and does not fill unresolved values with expectations. See `tool-use-mixture-methodology.md`.
