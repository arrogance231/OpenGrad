# Roadmap

OpenGrad proceeds from infrastructure to controlled measurement. A later phase is not considered successful without reproducible evidence and regression analysis.

0. Repository and research infrastructure
0.5. CPU-only pre-experiment validation
1. Baseline reproduction and directional residual profile
2. Tool-use behavioral taxonomy, dataset normalization, coverage audit, and contamination-safe mixture construction
3. Controlled source-baseline vs behavior-balanced vs residual-driven SFT ablation (M0/M1/M2, when feasible)
4. Full behavioral, external-benchmark evaluation and diagnosis
5. Preference optimization only if a concrete residual justifies it
6. On-policy distillation targeted at remaining residuals
7. Cross-model replication
8. Quantization and runtime evaluation
9. OpenWeights-derived downstream deployment studies
10. Speculative decoding and inference research, with capability data kept separate from MTP continuation data
11. Joint capability–efficiency optimization
